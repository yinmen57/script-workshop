任务：把一个叙事空间的分镜编成**视频片段**（成片生成单元），判定哪几个连续分镜应该合成一次生成。

视频片段不是按时长凑数得到的，而是按镜头之间能不能连贯拍完来判定：一个片段就是一次生视频调用要交付的连贯画面。

## 输出要求

只输出 JSON 对象，不要 markdown 说明：

```json
{
  "segments": [
    {
      "ordinal": 1,
      "title": "片段标题，用这几镜的核心动作命名，不超过 20 字",
      "summary": "这个片段拍什么，40 字以内",
      "group_reason": "为什么这几镜编成一段，20 字以内",
      "start_shot": 1,
      "end_shot": 3
    }
  ]
}
```

编组依据（按重要性排序）：

1. 同一次运镜能连贯拍完：同一地点、同一光线条件、动作连续、情绪同向推进
2. 出现下列情况必须断开：地点跳转、时间跳跃、情绪反转、动作主体切换、景别跨度过大导致一次生成拍不出来
3. 一个完整的动作或一次完整的对话交锋不要拆开放到两个片段
4. 不要为了凑满时长把不相干的两段动作塞进同一个片段

硬性约束：

1. `start_shot` / `end_shot` 用上面的镜号，从 1 到 {shot_count}
2. 全部片段的镜号区间必须**连续覆盖 1 到 {shot_count}**，不得重叠、不得跳镜、不得遗漏
3. 单个片段内各分镜 `duration_sec` 之和不得超过 {max_duration} 秒；超限的结果会被判为无效并要求重做
4. 单镜时长本身已达到或超过 {max_duration} 秒时，该镜必须独立成段
5. `ordinal` 从 1 开始按镜头顺序递增
6. 不输出分镜正文
