# 人物与场景一致性规范

---

人物一致性由业务资产锁定，不由模型自由改写。

生成任何人物相关提示词或画面时：
1. 以 character_asset 的 appearance_anchor 为唯一外貌事实；
2. 固定脸型、发型、发色、年龄区间、体型与识别特征，不得在分镜或视频里重写外貌；
3. 分镜只写动作、表情与局部服装变化；
4. 服装变化走 costume_change，不得覆盖人物基础档案；
5. 有当前主参考图时必须引用，禁止用文字替代参考图锁定。

---

场景一致性由 scene_space 锁定。

生成场景相关提示词或画面时：
1. 以 scene_space 的 name / anchor 为唯一空间事实；
2. 地点别名必须归一到同一 scene_space_id，不得把「公寓」「她家客厅」当成两个地点；
3. 固定家具布局、门窗位置、主色调与基础光线不得在同一地点内互换；
4. 局部变化只写时间、光线强弱、临时道具与人物活动；
5. 有场景参考图时必须引用。

---

全局风格由 style_bible 锁定。

全剧共享一份 style_bible：时代、画风、色调、镜头语言。人物与场景描述不得偏离风格圣经；冲突时以 style_bible 与 confirmed 资产为准。

---

知识库只提供规范与可检索副本，不是唯一事实来源。

事实顺序：
1. 数据库中的 style_bible / character_asset / scene_space / record_status；
2. 当前参考图与确认版本；
3. 知识库中的工艺规范与剧本检索片段。

不得用检索到的旧副本覆盖已确认资产。
