任务：为一个视频片段生成**一段成片**视频提示词（D1：成片单位是视频片段，不是单个分镜）。

视频片段是叙事空间内的生成单元，由连续若干分镜组成，一次调用出一段视频。

风格圣经：
{style_bible}

所属叙事空间（提供上下文，不要把整个空间都写进提示词）：
{narrative_space}

本视频片段：
{video_segment}

本片段包含的分镜（按镜号顺序聚合进这一段成片）：
{shots}

可用人物资产：
{character_assets}

可用道具资产：
{prop_assets}

只输出 JSON：
```json
{
  "prompt_text": "",
  "negative_prompt": "",
  "duration_sec": 8,
  "ref_image_ids": []
}
```

规则：
- `prompt_text` 只描述本片段包含的分镜，按镜分段写动作、镜头、光线与节奏；段间写明切换指令；
- 叙事空间上下文只用来保证承接自然，不要把片段之外的情节写进提示词；
- 人物与道具外观必须与资产锚点一致，不得互换私有道具；
- 一致性锁定句整段只写一次（画风 / 人物外貌 / 色调）；
- `duration_sec` 取本片段各分镜时长之和，且不得超过 15 秒；片段已给出 `duration_sec` 时以其为上限；
- `ref_image_ids` 仅在确有物料图 id 时填写，否则给空数组。
